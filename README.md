# 🎣 微风垂钓物语 2.0 (Whispering Waters Fishing)

一款基于原生 HTML5 Canvas + SVG + Tailwind CSS + Tone.js 开发的 2D/2.5D 休闲垂钓与生态观赏网页游戏。支持横向大世界自由探索、乘船远航、20 种独立建模鱼类互动收集、水族箱经营与悬赏订单玩法。

- **在线试玩**：https://whispering-waters-fishing.netlify.app

---

## ✨ 核心特色

- **2400px 四大横向生态海域**：
  - 🌾 **芦苇浅滩** (`0–600`)：温暖岸坡、摇曳蒲草与睡莲浅水区
  - 🌉 **微风木栈桥** (`600–1200`)：暖光风灯、栈桥甲板与路亚钓点
  - 🏝️ **翡翠湖心岛** (`1200–1800`，需乘船)：湖心奇石、樱花飘落与石灯笼
  - ⚓ **星渊沉船湾** (`1800–2400`，需乘船)：幽灵沉船、晶簇浮标与深海巨物
- **流畅 2.5D 转向手感与镜头前瞻**：
  - 步行与划船具备起步加减速、急停转向微尘、SOCD 后按优先防卡顿、船体水阻纵倾以及垂挂浮漂摆锤惯性。
  - 人物与船只采用连续立体转身过渡，配合轻点防抖死区与限速前瞻相机。
- **20 种鱼类独立双模建模与互动手感**：
  - 普通 / 稀有 / 史诗 / 传说 / 神话 5 档稀有度共 20 种鱼类，分别拥有独立分层动态 **SVG** 与关节/脊柱 **Canvas 2D** 模型（含河豚鼓胀、直立珊瑚海马、生物电鳗电弧、深海灯笼鮟鱇、幽蓝古鲟与星渊幻海龙等）。
  - 捕获展示框与图鉴卡片支持 2.5D 指针倾斜跟随、摆尾加速与轻戳回弹气泡交互；动态水族箱支持不同游姿与直接轻戳互动。
- **性格化遛鱼博弈与动态环境**：
  - 稳健、冲刺、沉底、幻影四大鱼类性格与跃水刺鱼 QTE；结合晴空 / 烟雨 / 雷暴 / 星陨极光天气、昼夜天色与限时「黄金鱼潮」。
- **水族箱经营、鱼篓订单与换装船坞**：
  - 收集观赏鱼产出门票收益、撒饵喂养成长、交付码头悬赏委托，解锁五阶钓竿/卷线器、橡木小艇/星辉天鹅画舫及 4 套服饰与头饰穿搭。

## 🎮 操作说明

### 桌面端键盘 / 鼠标
- `A` / `D` 或 `←` / `→`：左右步行或划船探索
- `E`：登船 / 靠岸下船
- `空格键` 或长按画布/主按钮：蓄力抛竿、咬钩提竿、遛鱼控制
- `W` / `↑`（或点击提示横幅/画布）：大鱼跃水空中刺鱼 QTE
- `1` ~ `4`：快速切换鱼饵
- `Esc`：关闭当前弹窗

### 移动端触控
- 支持独立移动按钮、快捷海域传送栏、单指/多指触控抛竿与 QTE 刺鱼。

## 🚀 本地运行

项目无需打包构建，使用任意静态服务器或自带 Node 服务脚本即可运行（需已安装 Node.js）：

```bash
node server.js
```

启动后在浏览器访问：

```text
http://localhost:18888/index.html
```
